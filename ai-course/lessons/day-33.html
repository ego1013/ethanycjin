商业模式：AI产品怎么赚钱？

技术能力 ≠ 商业价值——理解 AI 行业的钱从哪里来、到哪里去
📅 2026-05-22 Fri ⏱️ 约 40 分钟 🟡 中半衰期
🔥 开场问题

一个让整个行业尴尬的事实：

OpenAI 2025 年收入约 37 亿美元，亏损约 50 亿美元。全球最强的 AI 公司，用户数遥遥领先，每卖出 1 块钱就亏 1.35 块。

更尴尬的是：它并不孤独。Anthropic 2025 年收入约 8.8 亿美元但至少烧掉了 30+ 亿。整个 AI 行业的基础设施投资已超过 3400 亿美元，而产出的收入不到投资的 1/5。

问题来了：如果世界上最聪明的一群人做出了世界上最强的技术，仍然不知道怎么稳定赚钱——问题到底出在哪？

今天不讲技术，不讲产品设计——讲一个更前置的问题：AI 产品的钱从哪里来？它们的收费逻辑是什么？这些模式各自有什么根本性的结构弱点？

这些判断能力在你评估任何 AI 供应商、预测行业走势、甚至判断自己公司的 AI 项目该不该投入时，都是底层操作系统的一部分。

10 min

Why — 为什么理解商业模式比理解技术更持久

1. 技术迭代以月为单位，商业逻辑以年为单位

回忆 Day 28 的"操作系统保质期"分层——公司结论保质 3-6 个月，选型规则保质 6-12 个月。但商业模式的底层逻辑保质 3-5 年。

SaaS 的订阅制从 Salesforce（1999）流行到现在二十多年，中间技术栈换了无数轮，但收费逻辑的核心骨架没变。理解模型怎么收费比理解模型怎么训练对你的判断更持久有用。

核心观点

你判断一家 AI 公司的商业前景——不是看它技术多强（Day 22-27 已经搞明白了），而是看它能不能把技术变成可预测的、可持续的现金流。技术是发动机，商业模式是油路——发动机再好，油路设计不合理，车跑不远。

2. "免费+烧钱"不是商业模式，是赌博

2024-2025 年 AI 行业最普遍的收入方式是"先免费获客，未来再收费"。这个策略在社交网络时代验证过（Facebook/微信），但AI 的成本结构与社交网络完全不同：

  • 社交网络：边际成本趋近于零（多一个用户几乎不花钱）→ 先获客再变现合理
  • AI 产品：边际成本随使用量线性增长（每次调用都消耗 GPU 推理成本）→ 用户越多亏得越多

这意味着：AI 公司不能照搬互联网时代"先圈地再收割"的剧本——它必须从更早的阶段就想清楚每一块钱的来源。

渠道类比

这像极了渠道管理中的一个经典陷阱：签了一个"不赚钱但量大"的代理商，指望未来涨价——结果代理商一旦养成低价预期，涨价就跑。

AI 行业的免费用户也一样：一旦 ChatGPT 收费，用户就试 Gemini 或 DeepSeek 的免费版。低切换成本 + 无边际成本优势 = "先免费再收费"策略的结构性脆弱。

3. 你已经有了判断的工具，缺的是商业维度

Day 22-27 给了你供应商评估的五维度框架（战略赌注/护城河/商业化压力/路径风险/锁定程度），Day 32 给了你立项五问过滤器。

但这些框架有一个盲区——没有直接回答"这个产品/公司的收入模式健不健康"。今天补上这一块，让你的判断操作系统多一层"商业可行性"的滤镜。

20 min

What — AI 行业的六种核心商业模式

我把当前 AI 行业的商业模式归纳为六种，按照"离用户远近"排列——从底层基础设施到直接面向消费者。

每种模式有不同的收入逻辑、利润结构、和致命弱点。理解它们之间的关系，比记住某家公司的具体定价更重要。

💰 AI 商业模式光谱 · 从底层到用户 ┌─────────────────────────────────────────────────┐ │ 离用户远 离用户近 │ │ │ │ ① 卖铲子 ② 卖水 ③ 卖方案 ④ 卖工具 │ │ (芯片/云) (API) (解决方案) (订阅制) │ │ │ │ ⑤ 卖注意力 ⑥ 卖入口 │ │ (嵌入广告) (平台抽成) │ └─────────────────────────────────────────────────┘ 利润率 高→低→高→中→高→高 确定性 最高 ← → 最低 天花板 封顶 ← → 无限

模式 ① · 卖铲子：GPU/云基础设施

⛏️
卖铲子模式

谁在做：NVIDIA（芯片）、AWS/Azure/GCP（云计算）、CoreWeave（GPU 云）

收入逻辑：AI 行业越热，训练和推理需要的算力越多。不管谁的模型赢，只要行业在训练就得买 GPU。旱涝保收。

利润结构：NVIDIA 的 AI 芯片毛利率超过 75%——卖 1 块钱，7 毛 5 是毛利。2025 财年数据中心收入约 1150 亿美元。

渠道类比：像你们渠道体系里的物业/场地方——不管哪个品牌入驻商场、生意好不好，物业租金照收。
致命弱点：周期性。一旦"AI 冬天"到来或训练需求见顶（Day 8 数据墙），铲子没人买。NVIDIA 2018 年比特币矿难时股价跌了 50%。而且科技巨头都在自研芯片（Google TPU、Amazon Trainium、Meta MTIA）——"客户变对手"是最大威胁。

模式 ② · 卖水：模型 API 按量计费

💧
卖水模式 · Pay-per-Token

谁在做：OpenAI API、Anthropic API、Google Gemini API、DeepSeek API

收入逻辑：按调用量收费。每次 API 调用消耗 Token，按 Token 数量计费。调用越多收入越多。

利润结构：极薄。Token 价格战已经打了两年——GPT-4o 的 Token 价格比 GPT-4 降了约 90%。DeepSeek 的 R1 进一步将推理 Token 价格压到 OpenAI 的 1/10~1/30。

渠道类比：像按量计费的物流服务——每单抽几块钱运费。跑得越多收入越多，但竞争对手可以打价格战。而且一旦客户自建物流团队（自部署），你连单子都没了。
致命弱点：双重夹击。一边是价格战把利润往零压（DeepSeek 的开源+极低定价已经证明），另一边是成本下不去（推理依赖 GPU，GPU 依赖 NVIDIA 定价权）。收入增长的同时利润可能在萎缩——这就是 OpenAI "收入 37 亿，亏损 50 亿"的底层原因之一。
结构性困局

API 模式面临一个"大宗商品化"陷阱——当所有模型能力趋同（Day 27 三大趋势之一），Token 就变成了"电力"一样的同质化商品。电力公司很少有高利润。

这就是为什么所有卖 API 的公司都在拼命向"模式③④"转型——纯卖水养不活自己。

模式 ③ · 卖方案：垂直行业解决方案

🧩
卖方案模式 · Vertical SaaS + AI

谁在做：Harvey（法律 AI）、Abridge（医疗转录）、Glean（企业知识搜索）、Palantir AIP

收入逻辑：不卖裸 API，卖针对特定行业的完整解决方案——包含数据接入、工作流定制、合规适配、结果保障。按年订阅或按成果收费。

利润结构：远高于 API。Harvey 的法律 AI 订阅可以按律师人头收费 $500-1500/人/月，而背后的 API 成本可能只有 $20-50/人/月——行业知识和工作流设计是利润放大器。

渠道类比：这不是卖物流了，是做整合营销方案——帮品牌从选渠道到投放到数据监测全包。品牌方愿意付高价因为你解决了"完整的问题"而不是"一个环节"。
致命弱点：规模化困难。每个行业的"解决方案"都不一样——法律的合规逻辑、医疗的隐私要求、金融的审计规则——做深一个行业容易，横向复制到第二个行业几乎要重来。这就是为什么垂直 AI 公司"收入增长曲线"往往在 5000 万-1 亿美元附近开始放缓。

模式 ④ · 卖工具：通用 AI 工具订阅

🔧
卖工具模式 · Subscription SaaS

谁在做：ChatGPT Plus/Pro、Claude Pro、Cursor、Jasper、Notion AI、GitHub Copilot

收入逻辑：按月/年订阅收费。用户付固定费用获得一定额度的 AI 能力。ChatGPT Plus $20/月，Pro $200/月。

利润结构：取决于用户使用频率。轻度用户（每月用几次）= 高利润；重度用户（每天高强度使用）= 可能亏损。ChatGPT Pro 的 $200/月用户中，一部分的推理成本远超订阅费。

渠道类比：像代理商的年费制服务——签约时收固定管理费，不管当月帮你跑了几个活动。管理费覆盖得了就赚，覆盖不了就亏。关键是签到足够多的"低维护客户"来补贴少数"高维护客户"。
致命弱点：价值感知危机。$20/月 = 一杯星巴克 × 4。用户愿意为 ChatGPT 付 $20 的前提是"每周都用得到且明显有用"。一旦免费替代品足够好（DeepSeek、Gemini 免费版），从 $20 降到 $0 只需一个更好的免费竞品。而且"订阅疲劳"是真实的——用户不会同时订 ChatGPT + Claude + Gemini + Cursor + Notion AI 五个产品。

模式 ⑤ · 卖注意力：AI + 广告

📢
卖注意力模式 · AI-Powered Advertising

谁在做：Google（AI Overviews + 搜索广告）、Meta（AI 广告投放优化）、Perplexity（试水中）

收入逻辑：AI 不直接向用户收费，而是用 AI 提升广告效率，向广告主收费。Google 的核心逻辑：AI 让搜索更好用 → 更多人用搜索 → 更多广告展示机会 → 广告收入增长。

利润结构：可能是所有模式中最高的——Google 搜索广告的营业利润率超过 30%。前提是 AI 增强了而不是瓦解了广告模式（这正是 Google 的"创新者窘境"——Day 24）。

渠道类比：这是你最熟悉的领域——AI 优化广告投放 ROI。Meta 用 AI 把广告 CTR 提升了 20%+，广告主愿意花更多钱。本质是用 AI 作为效率放大器而非直接收入来源。
致命弱点：AI 可能瓦解广告模型本身。当 AI 直接给你答案（"最好的跑鞋是 XX"），你不再点 10 个搜索结果 → 广告展示量暴跌。Perplexity 这样的 AI 搜索引擎，每回答一个问题就"偷走"Google 5-10 次广告展示。

模式 ⑥ · 卖入口：平台生态抽成

🏪
卖入口模式 · Platform Tax

谁在做：OpenAI GPT Store（尝试中）、Apple Intelligence（嵌入生态）、微信/字节在 AI 应用分发上的布局

收入逻辑：成为 AI 应用的"分发平台"——第三方在你平台上发布 AI 应用，你抽 30% 的分成（类似 App Store 模式）。或者把 AI 嵌入已有平台增加粘性，间接提升核心产品收入。

利润结构：如果能成功，这是利润率最高的模式——Apple App Store 的 30% 抽成几乎是纯利润。但 AI 应用的平台生态还远未成型。

渠道类比：像商业地产/Shopping Mall——建好场地，招商引进品牌，每家抽 rent。你不需要自己卖货，只需要让足够多的"好店铺"愿意开在你的 Mall 里。
致命弱点：现阶段还是"赌未来"。GPT Store 到现在没有跑出类似 App Store 的爆款生态——大部分 GPTs 是个人娱乐项目而非付费级产品。"AI 应用"至今没有证明它是一个独立的应用品类——用户习惯是"打开 ChatGPT 聊"而非"在 GPT Store 里找 App"。

关键洞察 · 微笑曲线

AI 行业的利润分布呈"微笑曲线"——最上游（卖铲子）和最下游（卖方案/卖入口）利润最高，中间的 API 层利润最低。

这和制造业的微笑曲线一模一样（品牌设计和零售渠道赚钱，中间的代工厂利润最薄）。在你的渠道管理语境里：品牌方和终端门店赚钱，中间的分销商利润被两头挤压。

AI 公司的"API 中间层"正在经历一模一样的困境——上游 GPU 成本降不下来，下游客户的价格预期持续走低。

真实公司的模式组合拳

聪明的公司不会只押一种模式——它们会混合使用多种模式，互相支撑。让我们看看学过的五家公司分别怎么组合：

公司 主力模式 辅助模式 战略意图
OpenAI ②卖水 + ④卖工具 ⑥卖入口（GPT Store） API 获企业客户 + ChatGPT 获 C 端 → 双引擎覆盖
Anthropic ②卖水（API 为主） ④卖工具（Claude Pro） 安全可靠性溢价 → 企业愿意为"可信赖"多付钱
Google ⑤卖注意力 + ①卖铲子 ②卖水 + ④卖工具 AI 强化搜索广告 → 保住 1750 亿/年的核心收入
Kimi ④卖工具（C 端订阅） ②卖水（API） 单点场景极致体验 → 用户愿意为"读完整本书"付费
DeepSeek （不依赖商业化） ②卖水（极低价 API） 母公司量化基金养活自己 → API 价格战瓦解竞品定价
DeepSeek 的"反商业模式"

DeepSeek 是这张表里最特殊的一行——它几乎不需要从 AI 业务赚钱（Day 26 讲的"不赚钱也活得好的代理商"）。

这让它成为所有其他模式的价格破坏者：它的 API 定价不是基于"成本 + 利润"，而是基于"用最低价格让对手的 API 模式不可持续"。

这就像渠道管理中遇到一个不图利润、只图市场份额的搅局者——你没法在价格维度上打赢它，只能在服务、信任、深度定制这些它无法复制的维度上建立差异。

判断商业模式健康度的四个问题

学了六种模式和混合策略之后，给你一个实操框架——评估任何 AI 产品/公司的商业模式时，问这四个问题：

  1. 边际成本方向：用户增长时，每多服务一个用户的成本是下降（规模效应/卖铲子/卖入口）还是线性或上升（卖水/卖工具）？→ 前者有规模经济，后者增长越快亏得越快。
  2. 价格锚定来源：定价基于"用户获得的价值"（卖方案：帮律师省 30 小时→收 $1500 很合理）还是"资源消耗量"（卖水：按 Token 数量→价格永远被更便宜的竞品压）？→ 前者有定价权，后者没有。
  3. 切换成本高度：用户换到竞品有多难？深度定制 + 数据沉淀（卖方案）= 切换成本极高 → 续约率 90%+。通用 API 调用（卖水）= 换个 endpoint 就行 → 续约率取决于价格。
  4. 收入可预测性：是按月订阅的可预测现金流（卖工具/卖方案），还是按量波动的不确定收入（卖水/卖注意力）？→ 资本市场给可预测收入更高估值。
四问速查表

健康信号（4项全中 = 优秀商业模式）：边际成本下降 ✅ + 价值定价 ✅ + 高切换成本 ✅ + 可预测收入 ✅

危险信号（2项以下 = 商业模式脆弱）：边际成本线性 ❌ + 资源定价 ❌ + 低切换成本 ❌ + 波动收入 ❌

拿 OpenAI 的 API 业务过一遍：边际成本线性 ❌ / 按 Token 量定价 ❌ / 切换成本低 ❌ / 按量波动 ❌ → 0/4，这正是它亏损的结构性原因。

再拿 Harvey（法律 AI）过一遍：SaaS 边际成本递减 ✅ / 按律师人头的价值定价 ✅ / 法律数据 + 工作流深度定制 ✅ / 年度订阅 ✅ → 4/4，这是资本市场追捧垂直 AI 公司的原因。

So What — 这改变了你的哪些判断

1. 你的 AI 供应商评估多了一个维度

Day 22-27 的供应商五维度框架里，"商业化压力"是其中一项。现在你有了更精确的判断工具——不是"这家公司赚不赚钱"的模糊感觉，而是"它的商业模式结构是否健康"的系统性分析。

供应商评估升级

下次供应商说"我们 API 很便宜"——你的第一反应不应该是"好，省钱"，而是："它这个价格能持续吗？它的商业模式允许它一直这么便宜吗？如果它明年涨价 3 倍，我的系统能切换吗？"

Day 27 的风险对冲矩阵里有"价格突变"这一项——今天的商业模式分析告诉你哪些供应商更可能价格突变（卖水模式最可能，卖方案模式最不可能）。

2. 你的渠道管理 AI 项目也需要商业模式思考

你在腾讯推动的 AI 项目（渠道绩效 Agent、合同审核、门店巡检——Day 21/25/24），虽然是内部项目不直接卖钱，但也有"内部商业模式"——投入多少资源（人力 + API 成本 + 维护），产出多少可量化的价值（效率提升 × 人工成本节省）。

价值锚定 40h→2h = 节省 38 工时/月 × 渠道经理时薪 🟢 明确的效率价值可量化
切换成本 定制 Prompt + 业务逻辑 + 数据管道 🟢 沉没成本高，不会轻易放弃
可预测性 每月定期运行，使用量可预估 🟢 成本和产出可预期

3/4 绿灯——你的内部 AI 项目的"商业模式"是健康的。唯一的 🟡 是边际成本，可以通过 Day 26 的分层模型选型（Worker A/B 用 DeepSeek 压成本）来优化。

3. 行业终局判断：谁能活到最后

把商业模式维度加入你的判断操作系统后，一个更大的图景浮现：

终局推演

大概率活得好：模式①卖铲子（短期）+ 模式③卖方案（长期）+ 模式⑤卖注意力（如果广告模式不崩）

大概率被挤压：模式②纯卖水的公司——除非能转型为模式③④。"纯 API 公司"可能是 AI 行业的"纯代工厂"——技术能力顶级但利润被两头吃掉。

取决于执行：模式④卖工具（需要品牌忠诚度 + 高频使用场景） + 模式⑥卖入口（需要生态效应起飞）

一句话：越靠近"解决用户完整问题"的公司活得越好，越靠近"卖通用能力"的公司越危险——这和 Day 27 的"差异化从模型转向生态和工作流"完全一致。

🎯 Checkpoint · 选择题

场景：你部门要上一个 AI 合同审核系统。预算每年 50 万人民币。两家供应商来投标：

供应商甲：某大厂 AI 开放平台，提供通用合同审核 API。按 Token 计费，预估月成本 ¥8,000-12,000。功能全面，但合同审核只是其 100+ 个 API 能力之一。承诺"模型每季度升级"。

供应商乙：法律科技创业公司，专做合同审核 SaaS。按人头收费 ¥600/人/月（你们 15 个法务 = ¥9,000/月 ≈ ¥108,000/年）。内置行业合规模板、审核工作流、历史合同学习。需要签 2 年合同。

两家的 demo 测试中，准确率差距不大（甲 91%，乙 89%），但甲的错误更随机，乙的错误集中在极端边界场景。

你怎么选？

  • A. 选甲。准确率更高，成本更低（月省 ¥1,000），而且不绑两年合同更灵活。模型每季度升级意味着准确率会持续提升。
  • B. 选乙。虽然贵一些但专做法律场景有行业壁垒，错误集中在边界案例说明核心场景可靠，签两年反而说明对自己产品有信心。
  • C. 都先试用三个月再决定。不签长期合同，两家各跑一半合同量，用真实数据说话。
  • D. 先不急选——回去问法务团队三个问题：1）审核时最怕什么类型的错误？2）现在审核一份合同平均多久？3）系统需要学习我们自己的合同模板吗？答案不同，选型完全不同。

追问 1：如果你用今天的"商业模式四问"分析甲和乙——甲是模式②（卖水），乙是模式③（卖方案）。基于这个判断，哪家更可能三年后还在以同样的品质服务你？哪家更可能突然涨价或砍掉合同审核功能？

追问 2：甲准确率 91% > 乙 89%，看起来甲更好。但"错误随机"vs"错误集中在边界案例"——从法务使用者的角度，哪种错误模式更危险？为什么？

📌 知识卡片 · Day 33
  • 1. 六种商业模式：卖铲子（GPU/云）→ 卖水（API）→ 卖方案（垂直 SaaS）→ 卖工具（订阅制）→ 卖注意力（广告）→ 卖入口（平台抽成）。利润分布呈"微笑曲线"——中间的 API 层利润最薄。
  • 2. API 大宗商品化困局：当模型能力趋同，Token 变成同质化商品，纯 API 公司面临"电力公司化"——技术顶级但利润被挤压。这是 OpenAI 亏损的结构性原因之一。
  • 3. 商业模式四问：边际成本方向？价格锚定来源？切换成本高度？收入可预测性？4/4 = 优秀模式；≤2/4 = 结构脆弱。
  • 4. 终局判断：越靠近"解决用户完整问题"的公司（卖方案/卖入口）活得越好，越靠近"卖通用能力"的公司（纯 API）越危险。
  • 5. 供应商评估升级：不只看"今天的价格和能力"，还要看"它的商业模式是否允许它持续提供这个价格和能力"。Day 27 的风险对冲矩阵 + 今天的四问 = 更完整的供应商风险评估。
