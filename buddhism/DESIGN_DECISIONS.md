## 一、设计决策记录

### 1. 视觉风格
- **选定方案**：深夜墨金（方案A），与风格演示保持一致
- **理由**：暗色调与佛学的内观、沉静气质高度契合；金色作为点缀色呼应佛教美学中的金色传统
- **放弃方案**：暖米宣纸（方案B）虽然亲和但缺少庄重感；石板冷蓝（方案C）过于现代感，与佛学传统气质不够匹配
- **未来考虑**：可在后续加入风格切换功能（如演示页），但默认始终为深夜墨金

### 2. 页面结构简化
- **决策**：去掉风格演示中的"今日课程卡片"区块，直接从 Hero → 课程正文
- **理由**：卡片是导航入口的设计，但单课页面不需要再多一层点击。用户打开页面就应该直接进入内容
- **保留**：课程大纲放在底部，作为导航参考而非主要阅读区

### 3. 去掉风格切换按钮
- **决策**：生产版不提供风格切换
- **理由**：风格演示是给设计评审用的；正式课程页面应该有统一的视觉体验，不给用户"选择疲劳"

### 4. 增加入场动画
- **决策**：使用 IntersectionObserver 的 fade-in 动画
- **理由**：佛学课程的阅读节奏应该是渐进的，每个角色模块在滚动时缓缓浮现，呼应"停一下"的教学设计

### 5. 增加回顶按钮
- **决策**：右下角圆形回顶按钮，滚动超过 600px 出现
- **理由**：单课内容较长（7个角色区块 + 大纲），需要快速导航

### 6. 移动端适配
- **决策**：640px 断点下隐藏顶部导航链接，缩减内边距
- **理由**：导航链接在移动端占用空间过大，保留 logo 和进度即可

## 二、内容创作决策

### 1. 经文选择
- **选定素材**：《相应部·梵天劝请经》(SN 6.1)
- **理由**：
  - 符合第1讲"佛陀是谁"的主题——展现佛陀觉悟后最人性化的一面
  - 不是"人人都知道"的经文（多数人知道佛陀觉悟，但不知道他差点选择沉默）
  - 有极具体的"决定瞬间"：从倾向沉默到决定开口
  - 包含关键概念"阿赖耶"(ālaya)，为后续唯识学埋下伏线
- **放弃选项**：菩提树下觉悟的描述（太广为人知）；初转法轮的内容（留给第2讲）

### 2. 回声选择
- **选定素材**：阿沃·帕特 (Arvo Part) 关于沉默与第一个音符的言论
- **理由**：
  - 与佛陀"沉默→开口"的弧线形成精确的感受共鸣
  - 不是主题相似（音乐 vs 佛法），而是方法共鸣：都是关于"打破沉默的第一步需要什么理由"
  - 帕特的极简音乐（Tintinnabuli 风格）本身就是对"少量尘埃"理念的音乐实践
- **放弃选项**：马克·罗斯科"我不知道我在画什么"（演示版已用）；维特根斯坦（论师已引用）

### 3. 跨界者判断
- **决策**：第1讲不触发跨界者
- **理由**：第1讲的核心是"相遇"——学习者与佛法的第一次正式见面。不宜在第一讲就引入跨领域连接，那样会分散焦点

### 4. 沉默判断
- **决策**：第1讲不触发沉默
- **理由**：第1讲需要完整展示所有角色的运作方式，让学习者理解课程结构

## 三、修改建议（后续迭代）

### 高优先级
1. **课程进度持久化**：当前进度条是硬编码的。后续需要引入 localStorage 或后端存储，记录学习者的实际进度
2. **前后课导航**：增加"上一讲 / 下一讲"按钮，让用户可以在课程之间流畅切换
3. **大纲页独立化**：当前大纲嵌在第1课底部。当课程推进到5-10讲时，需要一个独立的大纲总览页（buddhism/outline.html）
4. **法义卡片截图优化**：加入一键截图保存功能（html2canvas），方便学习者保存法义卡片

### 中优先级
5. **阅读时间估算**：Hero 区域增加预估阅读时间（基于字数计算）
6. **暗色/浅色模式切换**：虽然默认暗色，但可以提供系统主题跟随的选项
7. **字体加载优化**：Noto Serif SC 体积较大，考虑使用 font-display: swap 和子集化
8. **锚点深链接**：每个角色区块支持直接跳转链接（#keeper, #body, #analyst 等）

### 低优先级
9. **修行日志功能**：在行者区块后增加一个可选的"今日觉察记录"输入框
10. **课程搜索**：100讲累积后，增加全文搜索功能
11. **社交分享**：Open Graph 元标签优化，分享时显示课程标题和预览
12. **音频版**：行者区块的练习指导可以考虑配合引导音频

## 四、技术栈决策

| 维度 | 决策 | 理由 |
|------|------|------|
| 框架 | 纯 HTML/CSS/JS，无框架 | 静态部署 GitHub Pages，无构建步骤，长期维护简单 |
| 字体 | Noto Serif SC + Noto Sans SC + EB Garamond | 中文衬线体 + 无衬线体 + 西文衬线体，覆盖经文/分析/巴利文三种场景 |
| 部署 | GitHub Pages (ego1013.github.io/ethanycjin/buddhism/) | 与其他项目保持一致的部署策略 |
| 动画 | IntersectionObserver + CSS transition | 轻量级，不依赖第三方库 |
| 响应式 | 640px 单断点 | 移动端 vs 桌面端，简洁够用 |
