# 唯识学100讲 · 网页课程站点

## 项目概述

一套完整的「唯识学100讲」静态网页课程，每讲约7000字，面向深度阅读者。无需登录/后端，纯静态站点，可离线打开。

## 项目结构

```
/
├── index.html                  # 导航总览页（含100讲卡片、筛选器）
├── lessons/
│   ├── lesson-001.html         # 第1讲详情页
│   ├── lesson-002.html         # 第2讲详情页
│   └── ...                     # ...
│   └── lesson-100.html         # 第100讲详情页
├── assets/
│   ├── style.css               # 完整设计系统
│   └── script.js               # 进度追踪、筛选、暗色模式、字号调节
├── README.md                   # 本文件
├── data.json                   # 100讲数据（供生成脚本使用）
└── generate.py                 # 站点生成脚本
```

## 快速开始

### 本地预览

直接在浏览器中打开 `index.html` 即可。或者使用任意静态文件服务器：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 设计特性

- **四角色认知分工系统**：每讲由持论者（Dhāraka）、转译者（Bhāṣāntara）、辩证者（Vivādin）、观行者（Yogin）四个固定角色协作完成
- **六种讲次类型**：常规讲、碰撞讲（⚡）、辩证讲（⚖）、元洞见讲（🔗）、模块收尾讲（✓）
- **暗色模式**：支持护眼暗色模式，偏好自动保存
- **字号调节**：A- / A+ 按钮，支持4档字号
- **进度追踪**：已读状态自动保存至 localStorage
- **响应式设计**：桌面端双栏（正文+侧边目录），移动端单栏
- **打印优化**：@media print 隐藏导航元素，仅保留正文

## 如何替换占位内容

当前所有讲次页面显示「内容筹备中」占位状态。当课程内容就绪后：

### 方法一：直接编辑 HTML（推荐）

1. 打开对应的 `lessons/lesson-XXX.html` 文件
2. 找到 `<div class="role-content">` 区块内的 `<p class="placeholder">内容筹备中，敬请期待。</p>`
3. 替换为实际文本内容，保持 `<p>...</p>` 段落结构
4. 同步更新法义卡片、经典引用、连接说明等区块

### 方法二：使用生成脚本

1. 将正式内容整理为对应格式的数据
2. 修改 `generate.py` 中的模板函数（`normal_body()`、`collision_body()` 等）
3. 运行 `python3 generate.py` 重新生成所有页面

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript
- 无构建工具依赖
- 中文字体：Noto Serif SC（衬线）+ Noto Sans SC（无衬线）
- 所有交互状态通过 localStorage 持久化
