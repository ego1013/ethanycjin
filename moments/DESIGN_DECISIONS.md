## 一、视觉设计决策

### 1. 整体风格定位
- **选定方案**：「老照片 × 纪实文学 × 电影字幕」交叉点
- **色调**：墨黑底（#0c0b0a）+ 羊皮纸文字（#e6dcc6）+ 哑金点缀（#c9a24b）
- **理由**：历史的厚重感，不是博物馆的冷，而是深夜读书的暖。暗色调与「在场感」叙事契合；羊皮纸色文字降低纯白的刺眼，模拟旧纸张；哑金作为唯一高饱和点缀，克制地承担「珍贵 / 时间」的隐喻
- **与站内其他课程的关系**：刻意区别于佛学课的「深夜墨金」（偏暖褐金）和 AI 课的无衬线现代感。本课用 **Playfair Display 衬线标题** 强化「时间感」，与无衬线的 AI 课程形成对比

### 2. 字体系统
| 用途 | 字体 | 理由 |
|------|------|------|
| 标题 | Playfair Display | 高对比度衬线，带 18-19 世纪印刷的纪实文学气质 |
| 引用 / 副标题 | EB Garamond（斜体） | 文学性的西文衬线，承担「电影字幕」的诗意感 |
| 正文 | 思源宋体 Noto Serif SC | 中文衬线天然的「时间感」，长文阅读舒适 |
| 标签 / 元信息 | 思源黑体 Noto Sans SC | 无衬线承担功能性信息，与衬线正文形成层次 |

### 3. 胶片颗粒（核心质感决策）
- **实现**：CSS `body::before` 叠加 SVG `feTurbulence` 噪点，`mix-blend-mode: overlay`，opacity 0.45
- **理由**：模拟老照片的银盐颗粒，让「历史」的质感渗透进界面本身，而非仅靠内容传达。这是本课视觉的灵魂，不可删除
- **附加**：`body::after` 加暖色径向晕影（vignette），模拟老照片边缘的暗角

### 4. 金色分割线
- **决策**：所有分割线统一为 `rgba(201,162,75,0.16)` 极细、低透明度金线
- **理由**：克制的奢感，不喧宾夺主。金色只在分割与点缀处出现，绝不大面积使用

### 5. 核心交互（四项，全部实现）
1. **顶部进度条**：红（#c0492f）→ 金（#c9a24b）渐变，随滚动推进 —— 暗示「你正在穿越时间」
2. **时间轴横条**（导航页）：可横向滚动的历史坐标，从公元前49年到2022年，按真实年代排序；已发布节点亮红点可点击，未发布为灰点
3. **现场 / 回响双色标签**：现场 = 红（#c0492f，热的、当下的）；回响 = 蓝灰（#6a7d8c，冷的、时间拉开后的）。贯穿 Hero 标签、目录讲次卡、卡片顶边
4. **卡片左侧金线 hover 滑下**：导航页讲次卡 `::before` 用 `transform: scaleY(0→1)` + `transform-origin: top`，hover 时金线从顶部滑下，像翻开一页书

### 6. 入场动画 & 回顶按钮
- IntersectionObserver 驱动的 fade-in，每个角色块滚动时缓缓浮现，呼应「现场→回响」的阅读节奏
- 右下角圆形回顶按钮，滚动超过 600px 出现

### 7. 响应式
- 720px 单断点：隐藏导航次级链接、收紧内边距、时间轴节点缩小、双讲卡改为单列

## 二、信息架构决策

### 1. 三级页面结构
```
根目录 index.html（Ethan's Lab）
  └─ 学习板块新增卡片「⚡ 改变世界的50个历史瞬间」
       └─ moments/index.html（100讲导航页）
            ├─ 时间轴横条（按年代）
            ├─ 四角色说明
            ├─ 10部 × 50瞬间目录（每瞬间含「现场/回响」双讲入口）
            └─ moments/lesson-NN.html（单讲页）
```

### 2. 面包屑导航（每页顶端）
- 统一格式：`🧪 Ethan's Lab / ⚡ 50个历史瞬间 / 第N讲 · 现场|回响 · 瞬间名`
- 固定在顶部导航栏下方，每一级可点击回溯

### 3. 导航页版式（基于课程大纲）
- 10部分组，每部含「人性母题」暗线标注（孤注一掷 / 系统崩溃 / 认知革命 / 尊严的代价 / 偶然与必然）
- 每个瞬间一张卡，下挂「现场（红）/ 回响（蓝灰）」两个讲次入口，状态分「已发布 / 待发布」
- 顶部指标条：50 Moments / 100 Lectures / 10 Parts / 4 Voices / 2071 Years

### 4. 单讲页结构（严格遵守大纲格式）
- **奇数讲（现场）**：Hero + 📍坐标卡 + 四幕（叙事者/解构者/摆渡人/挑战者）+ 📌现场卡片 + 彩蛋/预告 + 讲间导航
- **偶数讲（回响）**：Hero + 🔄回响地图（1年/5年/17年/100年/今天）+ 四幕（涟漪/为什么这结果/今天回响/历史真的改变了吗）+ 📌回响卡片 + 彩蛋/连接

## 三、内容创作决策

### 1. 瞬间 #33 的调整
- **原大纲**：坦克人（1989·长安街）
- **调整为**：石墙暴动之夜（1969·纽约）
- **理由**：① 规避政治敏感内容；② 石墙事件同样精准命中第七部「人权与尊严」主题、以及「没有名字的人成为象征 × 身份认同」的暗线设计；③ 保持课程整体结构与张力不变
- **影响**：导航页时间轴、目录、暗线标注均已同步

### 2. 字数保障
- 第01讲 ≈ 7550 中文字符，第02讲 ≈ 7100 中文字符，均达 ≥7000 标准
- 四幕字数比例遵循大纲：叙事者/解构者各 ≥2000，摆渡人/挑战者各 ≥1500

### 3. 与 Ethan 生命情境的连接（摆渡人 + 镜子模块）
- 第01讲：拉康「大他者凝视」「象征性弑父」、荣格「个体化/人格面具」、行为经济学「损失厌恶」；连接职场「卢比孔时刻」与 OpenAI 2023 董事会事件
- 第02讲：「凯撒型 vs 屋大维型」领导力、佛学「无我」的领导力、AGI 时代的「红线失效」博弈、组织管理的「单点故障」
- **手法**：暗线呼应，不明说，让读者自己发现（遵循暗线三「Ethan 的镜子」设计）

### 4. 挑战者的「被遗忘的声音」暗线
- 第01讲：河边洗衣服的女人
- 第02讲：追踪这个女人的家族三代，论证「结构的韧性」
- **目的**：贯彻暗线二，让读者意识到「改变世界的瞬间」对不同的人意味着完全不同的事

### 5. 史料诚实
- 挑战者明确指出「骰子已经掷出」无同时代一手记录、希腊语 vs 拉丁语版本的语义差异、吹笛陌生人为后世传奇
- 凡基于推断的内心描写，正文以 `.note` 样式标注（如「据载」「史料明确记载」）

## 四、技术栈决策

| 维度 | 决策 | 理由 |
|------|------|------|
| 框架 | 纯 HTML/CSS/JS，无框架 | GitHub Pages 静态部署，无构建步骤，长期维护简单 |
| 公共样式 | 抽离为 `moments/styles.css` | 100讲共享，单点维护视觉系统 |
| 字体加载 | Google Fonts `@import` + `display=swap` | 避免 FOIT，首屏先用 fallback 渲染 |
| 胶片颗粒 | 内联 SVG data URI | 无外部请求，零依赖 |
| 动画 | IntersectionObserver + CSS transition | 轻量，不依赖第三方库 |
| 导航页生成 | Python 脚本批量生成 100 讲链接 | 保证 50 瞬间 × 2 讲的编号、链接、状态零错误 |

## 五、修改建议（后续迭代）

### 高优先级
1. **批量生成剩余 98 讲**：当前仅发布第 1-2 讲，需按相同结构与字数标准产出第 3-100 讲
2. **进度持久化**：进度条 / 「已读」状态目前无记忆，可引入 localStorage 标记已读讲次
3. **法义卡片一键截图**：现场/回响卡片已为「可截图」设计（含 📌 标记），可加 html2canvas 实现一键保存
4. **元洞见节点**：大纲设计的「每20讲触发一次元洞见」（第20/40/60/80/100讲回响），需在对应讲次特殊处理版式

### 中优先级
5. **时间轴节点联动**：导航页时间轴可加「hover 显示核心张力 tooltip」（已实现 title 属性，可升级为自定义浮层）
6. **阅读时间估算**：Hero 区显示预估阅读时间
7. **锚点深链接**：每一幕（叙事者/解构者…）支持 `#act-narrator` 直链
8. **Open Graph 元标签**：分享时显示讲次标题与现场/回响标签

### 低优先级
9. **暗线可视化页**：单独页面展示三条暗线（人性恒常 / 被遗忘的人 / Ethan 的镜子）如何贯穿 100 讲
10. **音频版**：叙事者「现场」部分适合配音频朗读
11. **全文搜索**：100讲累积后加搜索
12. **打印样式**：`@media print` 优化，方便导出 PDF 收藏
